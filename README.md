## How to Add the Next Case Study (3-Beat Modular Workflow)
Every project in `index.html` follows the three-beat structure (**Problem &rarr; Action &rarr; Result**):

1. **Upload the Artifact:** Add your project PDF or link your GitHub repository in the root of `HenryAdler.github.io`.
2. **Copy the Slot in `index.html`:** Locate the `NEXT CASE STUDY SLOT` comment block inside `<div class="project-grid" id="project-grid">`.
3. **Fill in the Three Beats:**
   - **Problem:** State the specific technical bottleneck or failure mode.
   - **Action:** Specify the dataset, standard (ISO/ASME), simulation tool, or ML validation split used.
   - **Result:** Report the quantified metric or engineering decision validated.
4. **Update Filter Count & Commit:** Increment the `All (N)` counter in `.filter-pills` and push to `main`.
